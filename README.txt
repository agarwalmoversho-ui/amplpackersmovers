AGARWAL PACKERS & MOVERS — Static GitHub Pages + Formspree-ready website

Pages: index.html, services.html, about.html, tracking.html, locations.html, contact.html, quote.html

LOCAL PREVIEW
Open index.html in a browser. Tailwind CDN requires internet.

QUOTE/CONTACT SUBMISSION (no server needed)
1. Create a free account at https://formspree.io/ and create one form for Quote, one for Contact.
2. Copy each form's public endpoint ID.
3. Edit assets/form-config.js and replace REPLACE_QUOTE_FORM_ID and REPLACE_CONTACT_FORM_ID.
4. Test both forms before publishing. The forms send submissions directly to Formspree.
   Do not add private API keys to frontend code. Only Formspree's public form endpoint belongs here.

FREE GITHUB PAGES HOSTING
1. Create a public GitHub repository (e.g. agarwal-packers-demo).
2. Upload the contents of this folder to the repository root. Ensure index.html is at root.
3. Repository Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Select branch main and folder /(root), Save.
5. Wait for Pages to deploy. Your site URL will look like https://YOUR-USERNAME.github.io/REPO-NAME/

Forms are live only after Formspree endpoints are configured. Tracking is a demo interface unless connected to a shipment-tracking API.
Mobile drawer: slide-in navigation, overlay click and Escape to close.
Verify company details, logos, stats, city lists and claims before publishing.
